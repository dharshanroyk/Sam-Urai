# Sam-Urai
Cinematic motion landing page for Ghost of Tsushima, built with React, TypeScript, Vite and Tailwind CSS. Features a mouse-scrubbed video hero, typewriter text and a responsive layout. Built in 30 minutes with AI tools, and actively maintained with ongoing updates.
